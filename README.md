# ✨ Jeyasree S A — Portfolio

A stunning, single-page portfolio website built with pure HTML, CSS, and vanilla JavaScript. Designed with a futuristic dark aesthetic featuring glassmorphism, micro-animations, and a magical visual experience.

## 🌐 Live

**[View Portfolio →](https://jeyasree-667.github.io/js-portfolio667/)**

## 🎨 Design Highlights

- **Deep matte black** background with subtle noise grain texture
- **Electric cyan & soft violet** accent palette
- **Welcome screen** with staggered text animations and a unique scroll-drop prompt
- **Levitating profile photo** with floating animation and pulsing glow
- **Glassmorphism cards** with frosted-glass effect and hover-lift interactions
- **Typing animation** cycling through roles and taglines
- **Shimmer text effect** on the name heading
- **Floating particle system** with 25 ambient glowing dots
- **Vertical timeline** with glowing dots for experience and education
- **Smooth scroll-triggered fade-in** animations via IntersectionObserver
- **Fully responsive** — mobile-first with a frosted-glass hamburger nav

## 📐 Sections

| Section | Description |
|---------|-------------|
| **Welcome** | Dramatic intro screen with animated headline and scroll prompt |
| **Intro** | Profile photo + name + typed tagline + bio + CTAs |
| **About** | Bio paragraph with glassmorphic stat cards |
| **Skills** | Categorized skill pills — Languages, Frameworks, Tools & Data |
| **Projects** | 4 project cards with tech tags and links |
| **Experience** | Vertical timeline with internships and education |
| **Contact** | Email, GitHub, LinkedIn, LeetCode with hover-glow icons |

## 🛠 Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, glassmorphism, conic gradients, keyframe animations
- **Vanilla JavaScript** — Particles, typing effect, scroll observer, mobile nav
- **Google Fonts** — Space Grotesk · Red Hat Text · Fira Code

## 📁 Project Structure


## 🚀 Run Locally

Simply open `index.html` in any modern browser — no build tools or server required.

```bash

npx serve .
```
